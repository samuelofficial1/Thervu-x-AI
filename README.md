
# 🚀 Thervu X AI

> **POTTI X — Smarter Preparation. Stronger Performance.**

Thervu X AI is a multilingual competitive exam preparation platform focused primarily on **JEE & NEET**, with support for exams such as **CLAT** and more.

The platform is designed to make competitive-exam preparation more **accessible, engaging, and intelligent**, especially for students who prefer learning in **Tamil or English**.

## 🎯 Key Features

- 📚 JEE & NEET preparation
- 📝 Previous Year Questions (PYQs)
- ⏱️ Full-length & chapter-wise mock tests
- 📊 Performance and progress tracking
- 🌐 Tamil & English language support
- 🤖 AI-powered learning assistance
- 🎯 Chapter-wise practice
- 🏆 Score and performance analysis
- 🔄 Support for additional competitive exams

## 🌐 Supported Exams

### Primary
- JEE Main
- JEE Advanced
- NEET

### Planned / Additional
- CLAT
- Other competitive examinations
